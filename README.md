# Varun & Spandana – Wedding Invitation 💍

A digital wedding invitation web page for Varun & Spandana.

## 🌐 Live Website
Guests can view the interactive wedding invitation at:
👉 **[https://chinmaycholin.github.io/Varun-Spandana-Wedding/](https://chinmaycholin.github.io/Varun-Spandana-Wedding/)**

## 📲 Social Sharing & Link Preview
When this link is shared on WhatsApp, iMessage, Telegram, Instagram, Facebook, or Twitter, a rich cover preview card featuring the wedding invitation artwork is automatically displayed. Tapping or clicking anywhere on the preview card opens the interactive wedding invitation in the browser.

## 📁 Repository Structure
- `index.html`: Primary web page entry point configured with Open Graph and Twitter Card metadata for rich social previews.
- `Varun & Spandana – Wedding Invitation.html`: Original standalone invitation file with matching preview metadata.
- `cover.jpg`: Optimized 1200×630 landscape cover banner for WhatsApp, Facebook, iMessage, and Twitter link preview cards.
- `preview.jpg`: High-quality compressed portrait preview card (<300 KB for guaranteed WhatsApp mobile scraper compatibility).
- `Elegant Indian Wedding Invitation.png`: Original high-resolution cover invitation artwork.
